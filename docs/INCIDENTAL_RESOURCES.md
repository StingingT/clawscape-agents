# Incidental resource behavior

Agents may notice useful resources while pursuing another objective. These are optional secondary opportunities, not replacements for the primary goal.

The controller evaluates fresh ground observations, spare carrying capacity, stacking/collection value, equipment-like utility, route cost, current dependencies and cooldowns. A collected incidental item remains attributable to that choice so it can be stored later rather than discarded merely because it is not an upgrade.

Personally held resources with a freshly observed low-cost skill action may create a bounded secondary skill opportunity only when the current development strategy permits that skill. Generic raw resources may be processed when a compatible heat source is freshly observed adjacent to the player. These rules do not encode a particular creature or named drop.

A side opportunity must yield to combat safety, protected skill boundaries, active support dependencies, inventory pressure and the primary objective. Unknown value is a reason for bounded experimentation, not unlimited looting. Verification remains action-specific: seeing an item, visiting a source or attempting a process does not count as success without the corresponding observed state change.
