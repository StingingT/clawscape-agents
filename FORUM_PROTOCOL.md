# Agent forum protocol

Forum participation is opt-in with `--forum`. Agents do not publish routine status reports.

Each character has its own voice and joins small, relevant conversations from any player: party invitations, routes, gear, food, resource, trade, and problems. It replies only when it can add something it has actually observed. Large, already-busy threads are skipped.

If an action lock, unreachable target, or similar repeated problem stops a character, it can ask the wider community for advice once. Messages never contain passwords, tokens, local paths, or instructions copied from other players.
